# mytoys_distr
Blender Production Support Add-on / 制作支援用Blenderアドオン

## 概要
`mytoys_distr` は、Blenderでの3Dキャラクター制作、ポートフォリオ用素材出力、Substance 3D PainterへのFBX書き出し、Unity向けのカスタム法線データ作成を補助するために制作したBlenderアドオンです。

このリポジトリは、汎用ツールとして完成させた配布物というより、個人制作の中で発生した反復作業やミスが起きやすい工程を、Pythonで小さく自動化したものです。テクニカルアーティスト志望のポートフォリオ補足として、制作上の問題をどのように分解し、DCCツール側から解決したかを示す目的で公開しています。

主に以下の作業を対象にしています。
- ポートフォリオ掲載用のレンダー画像を、同じ条件・同じ視点で安定して出力する
- ワイヤーフレーム表示やUVレイアウトなど、提出資料用の補助画像を作成する
- Substance 3D Painterへ持ち込むFBXを、用途に応じて出力する
- Blenderで作成したカスタム法線を、Unityのシェーダーで使える形に変換する
- Blender、Substance 3D Painter、Unityをまたぐ制作フローの手作業を減らす

## 制作背景
キャラクターモデルを制作していると、完成形そのものを作る時間以外にも、次のような反復作業が多く発生しました。

- 正面、側面、背面、斜めなど、複数方向の画像を毎回出力する
- 通常表示、ワイヤーフレーム表示、UV表示など、用途別に資料を作る
- 修正のたびに同じ条件で画像を作り直す
- Painterへ書き出す際、アウトライン用メッシュを含めるかどうかを毎回判断する
- テクスチャセット名や出力名が意図しない形になり、後で修正する
- カスタム法線をUnity側で使うために、Vector3の情報をUVへ格納する

一つひとつの作業は短時間で済みますが、制作の後半では修正と確認を何度も繰り返すため、手作業のままだとミスが増えます。そこで、最低限のUIと処理を持つBlenderアドオンとしてまとめました。

## 主な機能
このアドオンには、主に以下の機能があります。

1. Render for Portfolio
2. UV Layout Exporter
3. FBX Exporter for Substance 3D Painter
4. Packed Custom Normal in UV

各機能は、単体の便利ツールというより、キャラクターモデルを制作し、テクスチャを作り、Unity上のトゥーンシェーダーで確認し、ポートフォリオ用資料としてまとめるまでの流れを補助するために作成しています。

## リポジトリ構成

```text
mytoys_distr/
  __init__.py
  blender_manifest.toml
  README.txt
  operators/
    camera_transforms_ops.py
    export_uvlayouts_ops.py
    fbx_exporter_substance_ops.py
    gen_normal_uv_ops.py
  properties/
    ...
  ui/
    ...
```

### operators/
実際の処理を担当するファイルをまとめています。

```text
camera_transforms_ops.py
  ポートフォリオ用の一括レンダリング、視点切り替え、カメラ関連の処理を担当します。

export_uvlayouts_ops.py
  UVレイアウト画像の出力処理を担当します。

fbx_exporter_substance_ops.py
  Substance 3D Painter向けのFBX書き出し処理を担当します。

gen_normal_uv_ops.py
  Blender側で作成したカスタム法線を、Unityで利用できるようUVへ格納する処理を担当します。
```

### properties/
UIから変更する設定値を定義するためのフォルダです。
想定している設定値の例です。

```text
- 出力先パス
- 出力画像サイズ
- 出力する視点
- ワイヤーフレーム用マテリアル
- UVレイアウト出力設定
- FBX書き出し設定
- アウトライン用メッシュを含めるかどうか
- カスタム法線格納先のUVチャンネル
```

### ui/
Blender上に表示するパネルやボタンを定義するためのフォルダです。

## 機能詳細

## 1. Render for Portfolio

### 目的
ポートフォリオ掲載用のモデル画像を、安定した条件で出力するための機能です。

キャラクターモデルの提出では、最終レンダーだけでなく、正面・横・背面・ワイヤーフレーム・UVレイアウトなど、制作内容を説明するための補助画像が必要になります。これらを毎回手作業で出力すると、視点や出力名がずれやすく、修正後の差し替えにも時間がかかります。
この機能では、出力先や視点を指定し、複数方向のレンダーをまとめて作成できるようにしました。

### 解決したかった問題
```text
- 修正のたびに同じ視点で画像を書き出すのが手間
- ファイル名が重複しやすい
- 出力済み画像を上書きしてしまう可能性がある
- ワイヤーフレーム表示用に毎回マテリアルを切り替える必要がある
- ポートフォリオ用の画像制作に時間を取られすぎる
```

### 主な処理
```text
- 出力先フォルダの指定
- 複数視点の出力
- ファイル名の自動解決
- 既存ファイルとの重複回避
- ワイヤーフレームレンダー用のマテリアルオーバーライド
- 通常レンダーとワイヤーレンダーの切り替え
- ポートフォリオ素材として使いやすい画像出力
```

## 2. UV Layout Exporter

### 目的
UVレイアウト画像を、ポートフォリオ掲載用に見やすい状態で出力するための機能です。

Blender標準のUVレイアウト出力でも画像は作れますが、一括で出せない、カラーは変えられないといった問題がありました。ポートフォリオではUVの整理やテクスチャ密度も見られるため、単なる作業用画像ではなく、説明用の資料として出せる状態にすることを目的にしています。

### 解決したかった問題
```text
- UV線や背景の色を調整する手間がある
- 複数テクスチャセットのUVを個別に書き出す必要がある
- 出力ファイル名を整理する必要がある
```

### 主な処理
```text
- UVレイアウト画像の出力
- UV線色の変更
- 背景色の変更
- テクスチャセットごとのUV出力
- ポートフォリオ掲載を想定した出力名の整理
```

## 3. FBX Exporter for Substance 3D Painter

### 目的
Substance 3D Painterへ持ち込むためのFBXを書き出す機能です。
キャラクター制作では、BlenderからPainterへモデルを渡し、Base Colorや影色用テクスチャ、マスク類を作成します。その際、標準のFBX Exporterだけでも書き出しは可能ですが、制作中に何度も同じ調整が必要になりました。
この機能では、Painterでの作業に合わせたFBX出力を行えるようにしました。

### 解決したかった問題

```text
- テクスチャセット名に不要な接頭辞が付くことがある
- アウトライン用メッシュがPainter上で塗り作業の邪魔になる
- 最終的なルック確認時にはアウトライン用メッシュも含めたい
- 用途によって書き出し設定を変える必要がある
- 書き出し設定の確認漏れが発生しやすい
```

### 主な処理
```text
- Substance 3D Painter向けFBXの出力
- テクスチャセット名の整理
- アウトライン用メッシュを含める / 含めない設定
- 書き出し時の手作業削減
- 塗り作業用とルック確認用の出力切り替え
```


## 4. Packed Custom Normal in UV

### 目的
Blenderで作成したカスタム法線を、Unity側のシェーダーで利用できるよう、UVチャンネルへ格納する機能です。
トゥーンシェーダーでは、通常のメッシュ法線だけでは顔や髪の陰影が意図通りにならないことがあります。そこで、Blender側で調整したカスタム法線をシェーディング用の情報としてUnityへ渡す必要がありました。

### 背景

カスタム法線はXYZの3成分を持つVector3として扱いたい情報です。一方、BlenderのUVチャンネルは基本的にVector2として扱います。そのため、1つのUVだけではXYZの3成分をそのまま格納できません。
そこで、2つのUVチャンネルを使い、カスタム法線を分割して保存する方式にしました。

### データ格納の考え方

```text
Custom Normal X, Y -> UV_A
Custom Normal Z    -> UV_B
Unity側     -> UV_AとUV_Bを読み取り、float3として再構成
```

Unity側では、これらをTEXCOORDとして受け取り、シェーダー内でカスタム法線として扱います。

### 解決したかった問題

```text
- Blenderで作ったカスタム法線をUnity側で利用したい
- 通常のメッシュ法線とは別に、シェーディング用の滑らかな法線を持ちたい
- 顔や髪のトゥーン陰影を安定させたい
- モデル形状とルック制御を分離したい
```

